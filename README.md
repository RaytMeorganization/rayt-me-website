# Rayt Me Website

This is the rayt me website landing page, which is being used for SEO and admin & business dashboard routing. It is developed in JavaScript using Next.js, with Shadcn/ui and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technologies Used

- **Framework**: Next.js
- **UI Components**: Shadcn/ui
- **Styling**: Tailwind CSS
- **Language**: JavaScript
